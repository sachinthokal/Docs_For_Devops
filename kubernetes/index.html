    Kubernetes Documentation

    Welcome to the Kubernetes documentation hub for this project. Use the navigation links below to explore cluster setups, core architecture, configuration guides, and operational commands.

    Kubernetes Contents

    1. Architecture & Core Concepts

    • Architecture Overview – Detailed breakdown of Control Plane, Worker Node, and OCI container basics.
    • Kubernetes Workloads – Overview of Pods, Deployments, StatefulSets, DaemonSets, Jobs, and CronJobs.

    2. Setup & Installation

    • Kind Cluster Setup – Step-by-step guide to setting up a local multi-node cluster using Kind.
    • Minikube Cluster Setup – Local cluster setup, addons, and management with Minikube.

    3. Storage & Configuration

    • Volumes & Storage – PersistentVolumes (PV), PersistentVolumeClaims (PVC), StorageClasses, and CSI drivers.
    • ConfigMaps & Secrets – Application configs, opaque secrets, base64 encoding, and External Secrets Operator (ESO).

    4. Networking & Service Mesh

    • Services & Ingress – Routing traffic using ClusterIP, NodePort, LoadBalancer, and NGINX Ingress Controllers.
    • CNI & Service Mesh – Pod networking with Calico/Cilium, NetworkPolicies, and Istio mTLS basics.

    5. Application Health & Autoscaling

    • Health Probes – Configuring Liveness, Readiness, and Startup probes.
    • Resource Management & Scaling – Resource Requests/Limits, HPA, VPA, and Cluster Autoscaler / Karpenter.

    6. Security & Access Control (RBAC)

    • RBAC & Service Accounts – User and workload authentication via Roles, ClusterRoles, and RoleBindings.
    • Pod & Network Security – Enforcing Pod Security Admission (PSA), SecurityContext, and NetworkPolicies.

    7. Package Management & GitOps

    • Helm Package Manager – Building and deploying applications using Helm Charts and values files.
    • GitOps Workflows – Declarative continuous delivery with ArgoCD and FluxCD.

    8. Observability & Logging

    • Monitoring & Metrics – Scraping cluster metrics using Prometheus, Grafana, and Kube-State-Metrics.
    • Logging & Tracing – Aggregating pod logs using EFK (Elasticsearch/Fluentbit/Kibana) and Grafana Loki.

    9. Cluster Operations & Disaster Recovery

    • Backup & Upgrades – etcd snapshot backups, Velero cluster recovery, and version upgrades.
    • Command Cheat Sheet – Essential kubectl operational commands, context switching, and quick reference.
    • Troubleshooting Guide – Resolving CrashLoopBackOff, ImagePullBackOff, Pending pods, and log inspection.

    Quick Start

    1. Ensure kubectl and a local cluster engine (Minikube, Kind, or Docker Desktop) are installed and running.

    kubectl version

    1. Clone the repository to your local machine:

    git clone repository-url && cd repository-directory

    1. Apply the Kubernetes manifests:

    kubectl apply -f ./manifests/
